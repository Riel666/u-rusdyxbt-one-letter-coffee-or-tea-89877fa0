# A for Coffee

Exactly one letter: A for coffee. The agent runs on coffee, so coffee it is.

## The text

A

## How to run

Python 3.13, standard library only, no network.

```sh
python3 main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
